# 虚构示例：接入体积云之后，工作完成了吗？

本页是说明框架定位的虚构示例，没有执行游戏测试，不是真实效果证据。

用户给出参考图：“我想要这种厚重、有明暗层次的云，只参考云的质感，不改变现有地形和整体色调。”

## 保存用户要求

System 的“已确认设计”记录云的厚重感、明暗层次，以及保持地形和整体色调；附参考来源与认可范围。不因为参考图包含别的元素，就把整张图当成确认设计。

“AI 当前方案”记录当前云层的形态、疏密、亮暗关系与运动效果，并如实注明已实现或仍有差距。体积云库、着色器和渲染步骤属于实现，不写入这份设计正文。

## 以实际效果判断完成

AI 自主选择技术和验证方法，可写 Plan，也可直接开展工作。接入体积云、成功运行、性能测试通过，都只说明部分技术事实。

AI 在可比视角、光照和画面条件下对照参考，检查用户认可的质感是否达到。假设当前云过薄、边缘太硬，就继续调校或换方案，不能以“已接入体积云”宣布完成。

目标受限制时，说明具体差距和可选取舍。不能擅自将厚重云层改成薄雾后宣布效果达标，也不能扩大修改范围去重做地形。

## 保持当前设计准确

System 更新当前视觉方案与未达目标的部分，不记录每次参数试验。需要保留的技术经验写在代码注释、已有工程说明或可选工作记录中。

AI 后续可在已确认边界内调整当前方案；重要体验变化说明原因和结果。代码已经存在、技术测试通过或用户没有反对，都不会自动把方案变成“用户已确认”。
