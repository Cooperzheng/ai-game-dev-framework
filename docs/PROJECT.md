## 使用与维护入口

本仓库是框架，没有游戏运行入口。初始化工具要求 Node.js 18+，无第三方依赖。框架维护时运行 `node tools/check.mjs`、`node --test tools/adopt.test.mjs`，并检查 Git 差异。

[AGENTS](../AGENTS.md) 保存一致性规则；[接入指南](ADOPTION.md) 用于接入与升级；[系统骨架](systems/README.md) 用于填写设计；[体积云示例](references/WORKED-EXAMPLE.md) 解释体验要求如何决定完成。

本页描述框架自身，不复制为目标游戏的白皮书；初始化工具生成待填写的游戏 PROJECT。
